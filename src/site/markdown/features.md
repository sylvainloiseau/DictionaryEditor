# Features

*Overview of what the editor can do*

## Navigation

- **Objects**: entries, senses, examples, notes, variants, etymologies, relations
- **Languages**: object languages, meta-languages
- **Category browser**: grammatical info, traits, annotations, note types, relation types, translation types, fields
- **Configuration**: description, language management, etc.

## Tables: columns and filters

- A **Columns** button above each table (Ctrl+Shift+K) chooses, orders and removes the columns. A chip per language shows or hides each language of a multilingual text.
- The available columns are the component's properties, fields, traits, notes and annotations, the number of its subcomponents (direct and at all levels), and the properties of its parent and of every ancestor.
- **Preferences ▸ Tables** shows the columns of every table in one place. A right-click on a column header can hide the column, keep one language, or filter by the column.
- Each column has a filter in its header: text (match case, regular expression, is empty…), values to tick with their counts, or a range with a histogram for numbers and dates.
- Multilingual texts can be edited in the cells. Typing in an empty field or note creates it.
- The active filters are listed above the table and kept for the session. Empty cells are hatched (**View ▸ Mark empty cells**).

## Category browser

A view by category, with filters, sorting by frequency, and an **Access the corresponding objects** button that shows the entries, senses or examples having a given value. See [Category browser](category-browser.html).

## Dictionary configuration

- Language management (object languages and meta-languages): adding and removing
- Note types, translation types, annotations, relations
- Field and trait definitions (**New definition**)
- Ranges (taxonomies) in the header

See [Configuration](configuration.html).

## Tools

- Validation of the dictionary
- CSV export
- Undo / Redo
