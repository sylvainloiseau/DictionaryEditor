# Configuration

*Dictionary configuration*

The configuration adds and removes the object languages and the meta-languages. The object languages are used for the lexical forms; the meta-languages for the definitions and translations.

- Language management (object languages and meta-languages): adding and removing
- Note types, translation types, annotations, relations
- Field and trait definitions (**New definition**)
- Ranges (taxonomies) in the header
