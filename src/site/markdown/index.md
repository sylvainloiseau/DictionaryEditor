# Multilingual Dictionary Editor

*Technical documentation*

A multilingual dictionary editor for the LIFT format: a JavaFX application to create, edit and manage lexicographic dictionaries, with support for object languages and meta-languages.

The application is a Maven project. It relies on the [lift-api](https://github.com/sylvainloiseau/lift-api) library to read and write LIFT files, and adds the JavaFX graphical interface. It needs Java 25 and Maven 3.x.
