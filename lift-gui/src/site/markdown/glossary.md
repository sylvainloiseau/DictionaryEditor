# Glossary

*Definitions of the technical terms of the project*

LIFT
: Lexicon Interchange Format, a standard XML format for lexicographic dictionaries.

Entry
: The basic lexical unit: a word or an expression, with its senses.

Sense
: A definition or translation of an entry in a meta-language.

Example
: A sentence illustrating the usage of a sense.

Trait
: A name/value pair that categorizes an element (e.g. `grammatical-info`).

Annotation
: Metadata attached to an element (note, field).

Object language
: The language described by the dictionary (lexical entries).

Meta-language
: The language of the definitions and translations.

Category browser
: A view by category (traits, note types, etc.).
