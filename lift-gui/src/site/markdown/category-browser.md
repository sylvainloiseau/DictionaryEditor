# Category browser

*A view by category, with filters, sorting by frequency, and an **Access the corresponding objects** button that shows the entries, senses or examples having a given value.*

## Navigation

The category browser lists the categories of the dictionary: grammatical info, traits, annotations, note types, relation types, translation types and fields. Each view shows the values with their frequency, and gives access to the objects that have them.

## Available views

- **Grammatical info**: the grammatical categories
- **Traits**: name/value pairs (identical rows are merged)
- **Annotations**: metadata
- **Note types**: the hierarchy of the notes
- **Relation types**: relations between entries
- **Translation types**
- **Fields**: custom fields
