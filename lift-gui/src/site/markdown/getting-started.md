# Getting started

*A quick start with the editor*

1. Install Java 25 and Maven.
2. Clone the repository and run `mvn install -DskipTests`.
3. Launch the application with `mvn javafx:run`.
4. Open or create a `.lift` file.
5. Explore the navigation tree and the [category browser](category-browser.html).

→ See also [Installation](installation.html).
