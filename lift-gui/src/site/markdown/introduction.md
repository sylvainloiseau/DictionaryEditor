# Introduction

*Overview of the project*

The Multilingual Dictionary Editor is a JavaFX application for creating and managing lexicographic dictionaries in the LIFT format (Lexicon Interchange Format).

## Goals

- Create and edit multilingual dictionaries
- Support object languages and meta-languages
- Manage entries, senses, examples, traits and annotations
- Export and validate the data in the standard LIFT format

## Audience

This documentation is for linguists, lexicographers and developers who want to use the project or contribute to it.
